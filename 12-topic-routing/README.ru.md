# 12 — topic-routing

**Целая многоагентная система (multi-agent) в одном чат-приложении: топики Telegram как домены, ignore-списки как стены, личные сообщения (DM) как стойка регистрации.**

> Мы держим несколько ролей и десятки cron-дайджестов в одной группе, где каждый
> домен получает собственный топик. Человек получает одного бота для общения;
> роли получают изоляцию; ничто не просачивается через стены. Эта папка —
> эталонная архитектура.

## Схема соответствия

| Понятие | Механизм Telegram | Почему это работает |
|---|---|---|
| Изоляция доменов | топик на домен (commutes, releases, health, kitchen, alerts, ops) | доставка адресуется по топику; человек читает то, что хочет, когда хочет |
| Стены | ignore-список на уровне шлюза для каждого профиля роли | роль буквально не может видеть приватный топик — контроль механический, а не поведенческий |
| Стойка регистрации | DM / основной топик | человек общается с ОДНИМ ботом; маршрутизация внутренняя (см. `04/docs/routing.md`) |
| Ops-канал | топик, который по умолчанию никто не читает | супервизоры, guards и sweep-отчёты идут сюда; важные алерты ТАКЖЕ попадают в DM |
| Одноразовые напоминания | DM, фиксированный текст, самоотключение | ноль контекста, ноль токенов, невозможно пропустить |

## Правила, обеспечивающие устойчивость

1. **Источник доставки — факт из записи задачи (job record)**, а не предположение — проверьте, куда доставляет задача, прежде чем винить «бота».
2. **Роли отчитываются в свой топик; координатор отчитывается человеку.** Сырой вывод роли по умолчанию никогда не попадает в DM.
3. **Приватные топики существуют только в мире координатора** — все остальные роли держат их в ignore-списке И в границах своего SOUL.
4. **Алерты — исключение из правила топиков**: всё, что требует человека *сейчас* (нижний порог баланса, эскалация супервизора, перезапуск watchdog), идёт в DM, а не только в ops-топик. Топики — для привычек чтения; DM — для внимания.
5. **Гигиена тредов**: дайджесты дедуплицируются за счёт continuity (непрерывности), поэтому топик, молчавший всю неделю, продолжает молчать — тишина — это фича (см. `05/delivery-policy.md`).

## Фрагменты конфигурации (пример)

```yaml
# per role: which topics exist in its world
role: chef
ignore_topics: [private, ops, medicine]   # walls are mechanical
report_topic: kitchen

role: operator
ignore_topics: [private, kitchen]
report_topic: ops
```
