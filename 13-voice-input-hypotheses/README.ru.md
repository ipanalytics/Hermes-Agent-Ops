# 13 — voice-input-hypotheses

**Защита агента от его собственного голосового канала: считайте каждое услышанное
имя гипотезой и проверяйте, прежде чем читать лекцию.**

> Голосовая транскрипция искажает доменные термины — стабильно, изобретательно
> и с полной уверенностью. Агент, который принимает транскрипт за факт, будет
> читать пользователю лекцию о его собственной кладовой, планировать не то
> блюдо, покупать не ту деталь. Эта папка: сценарий сбоя, паттерн и конфигурация.

## Реальный сбой (обезличенный)

Пользователь (голос): «use the green halapeno, the red one is softer…» — в
транскрипте значилось «jalapeño peppers». Ассистент выдал уверенную лекцию о
сортах свежего перца чили. В действительности пользователь имел в виду два
*соуса в бутылках* из местного магазина; речь шла о рецепте маринада,
требующем одну чайную ложку — чайную ложку соуса в бутылках, а не нарезанного
перца. Цена: доверие плюс неверный план рецепта. Транскрипт был неправ именно
так, как неправы транскрипты: правдоподобные слова, невозможный смысл.

## Паттерн

1. **Гипотеза, а не факт.** Любой доменный термин, поступивший через голосовой
   канал, помечается как непроверенный в рабочей памяти текущего хода.
2. **Сначала сверяйте с миром пользователя.** Файлы инвентаря, списки рецептов,
   история покупок и (для имён собственных) предыдущие сообщения самого
   пользователя — источник истины (ground truth), а не транскрипция и не
   мировая модель самой модели.
3. **Возражайте вслух, дёшево.** Если термин противоречит источнику истины,
   скажите об этом одной строкой и спросите — никогда не выдавайте уверенную
   лекцию, построенную на неверно расслышанном слове.
4. **Записывайте искажение.** Каждая подтверждённая голосовая путаница
   становится однострочной записью в SOUL роли («голос говорит X → проверь
   Y»), чтобы следующий случай выявлялся собственной памятью модели,
   а не удачей.

## Конфигурация

```yaml
# per role SOUL, "historical protection" section
voice_pitfalls:
  - transcript "jalapeno/siracha/gochujang" -> bottled sauces, NOT fresh produce
  - transcript "draniki/dranky" -> potato pancakes (local dish)
  - transcript "redmi file" -> README file
  rule: names from voice input are hypotheses; verify against inventory/files before acting
```
