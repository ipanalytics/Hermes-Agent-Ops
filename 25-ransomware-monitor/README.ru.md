Сторож ленты, который говорит только новое. Читает публичную ленту отчётов об атаках
шифровальщиков, держит файл состояния со всем уже виденным, сверяет каждый пункт с регионами,
которые мне нужны, и молчит, когда нового нет.

## Обзор

Ленты утечек шумят по-своему: один и тот же случай публикуют повторно, описание — стена HTML,
а поля с регионом нет вовсе. Мне от такой ленты нужны две вещи — дельта и регион, и обеих в
выдаче не лежит.

Сторож хранит в файле состояния время последнего запуска и до 2000 идентификаторов, поэтому
задание по расписанию может идти каждые полчаса и молчать сутками. Регион определяется по
словарю городов и названий компаний для DE/AT/CH/RU/US, потому что двухбуквенный код
встречается в обычных словах: `(DE)` считается, `deal` — нет.

## Как работает

1. Забирает ленту с браузерным user agent, таймаут 45 секунд, три попытки.
2. Разбирает пункты стандартной библиотекой — без feedparser и requests.
3. Выбрасывает всё старше прошлого запуска, остальное кладёт в файл состояния.
4. По каждому новому пункту достаёт группу и жертву из заголовка, снимает HTML с описания и
   ищет токен региона или знакомый город.
5. Печатает до 25 новых пунктов с берлинским временем ровным блоком — и ничего, если дельта
   пуста.

## Быстрый старт

```bash
export RANSOM_RSS="https://www.ransomware.live/rss"      # адрес ленты
export RANSOM_STATE="~/.hermes/data/ransom_rss_state.json"
python3 ransom_rss.py
```

Пример для расписания (каждые 30 минут, по замыслу молчаливый):

```
*/30 * * * * RANSOM_STATE=~/.hermes/data/ransom_rss_state.json python3 ~/.hermes/scripts/ransom_rss.py
```

## Использование

```
python3 ransom_rss.py            # дельта с прошлого запуска
python3 ransom_rss.py --help     # подсказка и переменные окружения
```

## Ограничения

- Регион определяется по словарю: компания, названная как город в другой стране, попадёт не в
  ту корзину. Список токенов лежит в скрипте и предназначен для правки.
- Лента — публичный агрегатор: она перепубликует заявления с площадок утечек, а это не
  проверенные инциденты. Считай выдачу зацепкой, а не сводкой.
- Первый прогон на пустом состоянии покажет всё текущее окно ленты. Заполнить файл состояния
  заранее — и не будет стены старых пунктов.
