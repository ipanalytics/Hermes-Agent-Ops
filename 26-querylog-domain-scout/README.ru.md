Этот модуль анализирует лог запросов AdGuard Home, чтобы определить, какие домены запрашивают устройства. Он ведет базу данных известных пар домен-устройство и генерирует отчеты о новых наблюдаемых доменах.

## Обзор

Анализатор доменных запросов извлекает данные запросов доменов из querylog.json AdGuard Home, обрабатывает их для определения новых запросов доменов по устройствам-клиентам и ведет локальную базу данных всех наблюдаемых пар домен-клиент. Он помогает отслеживать, какие домены используют ваши устройства, и выявлять новые домены, которые появляются со временем.

## Как это работает

Модуль подключается к экземпляру AdGuard Home по SSH для получения файла querylog.json. Он анализирует записи лога для извлечения IP-адреса клиента, запрашиваемого домена, метки времени и статуса блокировки. После фильтрации технического шума он обновляет локальную базу данных SQLite новыми парами домен-клиент. Модуль может работать в двух режимах: baseline (обработка всего лога) или tick (обработка только последних записей).

## Быстрый старт

```bash
# Установите переменные окружения
export ADGUARD_HOST="your-adguard-server"
export SSH_KEY_PATH="~/.ssh/adguard_key"
export DATABASE_PATH="./ag_scout.db"

# Выполните полный сбор (первый запуск)
python3 ag_domain_scout.py --mode baseline

# Выполните инкрементальное обновление
python3 ag_domain_scout.py --mode tick

# Сгенерируйте отчет о новых доменах за последние 7 дней
python3 ag_domain_scout.py
```

## Использование

```bash
python3 ag_domain_scout.py [options]

Опции:
  --mode MODE          Режим: 'baseline' (весь лог) или 'tick' (последние записи) [по умолчанию: tick]
  --days N             Отчет о доменах новее чем N дней [по умолчанию: 7]
  --tail-bytes N       Размер хвоста лога для чтения в режиме 'tick' [по умолчанию: 8000000]
  --no-ingest          Только показать отчет, не обновлять базу данных
  --quiet              Тихий режим для cron задач
  --alerts             Показать только проблемы с блокировкой
```

## Вывод

- Файл базы данных с парами домен-клиент и временными метками
- Консольный отчет о новых доменах, сгруппированных по клиентам
- Статус эффективности блокировок для добавленных правил

## Ограничения

- Требует SSH-доступа к серверу AdGuard Home
- Зависит от согласованности формата querylog.json
- Может потребовать настройки сопоставления CLIENTS для точной идентификации устройств
