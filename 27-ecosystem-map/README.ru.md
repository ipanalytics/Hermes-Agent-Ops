Этот модуль создает живую карту экосистемы агента, отображающую задания, профили и связи. Модуль отслеживает cron-задания и их состояния, обеспечивая всесторонний обзор запланированных задач агента.

## Обзор

Скрипт карты экосистемы создает представление в реальном времени всех запланированных задач в системе агента Hermes. Модуль запускает его как no_agent-cron каждую неделю в понедельник в 05:30 UTC, чтобы отслеживать состояние всех заданий, профилей и целей доставки. Скрипт группирует cron-задания по целям доставки и классифицирует их по состоянию (активные, на паузе, завершенные). Он ведет файл состояния для обнаружения изменений между запусками и сообщает только о значимых обновлениях.

## Как это работает

Модуль читает данные заданий из `~/.hermes/cron/jobs.json` и информацию о профилях из `~/.hermes/profiles/`, чтобы получить полную картину экосистемы. Скрипт группирует cron-задания по целям доставки и категоризирует их по состоянию (активные, на паузе, завершенные). Он поддерживает файл состояния для обнаружения изменений между запусками и только отображает значимые обновления.

## Быстрый старт

```bash
# Запустить скрипт напрямую
python3 ecosystem_map.py

# Или настроить как cron-задание
# 30 5 * * 1 python3 ecosystem_map.py
```

## Использование

Скрипт автоматически читает из стандартных расположений Hermes и создает:
- Полная карта экосистемы в `~/.hermes/data/ecosystem_map.md`
- Файл состояния в `~/.hermes/data/ecosystem_map_state.json`
- Отчет об изменениях выводится в stdout (при наличии изменений)

Установите переменные окружения для пользовательских ID чатов:
- HERMES_GROUP_CHAT - ID группового чата с темами
- HERMES_MYNET_CHAT - ID чата MyNET
- HERMES_OPERATOR_CHAT - ID чата оператора

## Выводы

- Карта экосистемы в формате Markdown, показывающая все задания по целям доставки
- Список профилей с пометкой основного профиля
- Раздел проблем с выделением неудачных заданий
- Дельта изменений, показывающая новые/удаленные/возобновленные задания
- Отслеживание состояния для непрерывного мониторинга

## Ограничения

- Требует доступа к структуре данных cron-заданий Hermes
- Зависит от определенных путей файлов в каталоге ~/.hermes
- Переменные окружения требуются для настройки пользовательских конфигураций чатов
- Отслеживает только запланированные и приостановленные задания, не включая однократные завершенные задания в обнаружении изменений
