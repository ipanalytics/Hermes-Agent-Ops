Скрипт генерирует ежедневный отчет о стоимости "думающего слоя" и потолке расходов. Он вычисляет расходы из базы данных состояния и получает информацию о текущем балансе из API.

## Обзор

Я анализирую затраты, связанные с "думающим слоем" экосистемы агента. Это включает в себя отслеживание расходов на расширенные модели, такие как M3, и расчет суточных лимитов расходов для контроля затрат. Мой отчет показывает текущее использование, среднесуточные значения и информацию об оставшемся балансе.

## Как это работает

Я подключаюсь к базе данных SQLite, содержащей данные об использовании моделей сессии, чтобы рассчитать затраты для моделей "думающего слоя". Я получаю информацию о текущем балансе из таких API, как OpenRouter и DeepSeek. Затем я объединяю эти данные в исчерпывающий ежедневный отчет, показывающий тенденции расходов и пороговые значения.

## Быстрый старт

```bash
python3 thinking_layer_cost.py
```

Убедитесь, что переменные окружения установлены для доступа к API:
- OPENROUTER_API_KEY
- DEEPSEEK_API_KEY

## Использование

Запустите скрипт напрямую, чтобы сгенерировать ежедневный отчет:

```bash
# Сначала установите переменные окружения
export OPENROUTER_API_KEY="ваш_ключ_здесь"
export DEEPSEEK_API_KEY="ваш_ключ_здесь"

# Сгенерировать отчет
python3 thinking_layer_cost.py
```

Скрипт выведет форматированный отчет с информацией о стоимости, суточных лимитах и текущем статусе.

## Выводы

- Ежедневная стоимость моделей "думающего слоя"
- Общие ежедневные расходы по всем моделям
- Пиковые и среднесуточные расходы за последнюю неделю
- Текущие балансы сервисов API
- Оценка срока службы на основе средних расходов
- Индикатор статуса, показывающий, превышают ли расходы пороговые значения

## Ограничения

- Требуется доступ к базе данных состояния (state.db) с данными об использовании модели сессии
- Необходимы действительные ключи API для проверки баланса сервисов
- Зависит от определенной конфигурации переменных окружения
- Работает только с часовыми поясами UTC для вычисления дат
