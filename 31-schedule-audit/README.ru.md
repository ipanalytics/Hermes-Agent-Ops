Аудит расписаний выявляет тяжелые задачи планировщика, которые можно перенести на ночь для снижения затрат и оптимизации использования ресурсов. Анализирует паттерны потребления токенов и находит задачи, которые не зависят от времени выполнения.

## Обзор

Я провожу аудит запланированных задач, чтобы выявить те, которые потребляют значительные вычислительные ресурсы, но не чувствительны ко времени выполнения. Я анализирую паттерны потребления токенов и определяю кандидатов для переноса на ночное время, когда стоимость обработки ниже, а нагрузка на систему минимальна.

## Как это работает

Я изучаю файл jobs.json, содержащий запланированные задачи, и сопоставляю его с usage_audit.jsonl, который содержит данные о потреблении токенов. Я классифицирую задачи по среднему потреблению токенов и чувствительности ко времени. Тяжелые задачи, нечувствительные ко времени, определяются как кандидаты для переноса на ночное время.

Скрипт различает задачи, критичные ко времени (например, утренние процедуры или операции, зависящие от времени), и гибкие задачи (например, аудиты, исследования, переводы), которые могут быть перенесены без последствий.

## Быстрый старт

```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить аудит без внесения изменений
python schedule_audit.py

# Применить предложенные изменения для переноса задач
python schedule_audit.py --apply
```

## Использование

Скрипт требует два входных файла:
- `jobs.json`: содержит конфигурацию запланированных задач
- `usage_audit.jsonl`: содержит данные о потреблении токенов в формате JSONL

Я анализирую потребление токенов по задачам и определяю те, которые в среднем потребляют более 200 000 токенов как тяжелые задачи. Задачи, потребляющие более 100 000 токенов, помеченные как гибкие и не критичные ко времени, являются кандидатами для переноса на ночное время.

При применении изменений я создаю резервные копии оригинального файла jobs.json перед внесением изменений.

## Выводы

- Список тяжелых задач планировщика с их средним потреблением токенов
- Список задач, которые можно перенести на ночь
- Резервная копия оригинального jobs.json перед применением изменений
- Файл отката с информацией о внесенных изменениях

## Ограничения

- Требуются оба файла: jobs.json и usage_audit.jsonl
- Время-критичные задачи определяют регулярные выражения, которые могут потребовать настройки
- Ночное время зафиксировано как 0-5 часов по UTC

## Структура

- `schedule_audit.py`: основной скрипт для анализа и переназначения задач
- `requirements.txt`: зависимости
- `tests/`: модульные тесты
- `examples/`: примеры входных данных
