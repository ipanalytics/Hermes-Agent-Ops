## Задача
- Перевести сборку релизов на детерминированный коллектор: джоб подбирал карточки сам и жёг 44% суточного расхода.

## Решения
- Сбор идёт скриптом releases_collect.py, модель только форматирует готовую подборку (~15 строк промпта вместо 600).
- Гейт выпуска по умолчанию dry: помечаем подозрительные карточки, но не блокируем выпуск, пока не починен разбор BTIH.
- Ночные джобы не трогаем: их расход ниже порога чувствительности.

## Ограничения
- Не менять расписание дневных выпусков
- Пары tool_call и результат не разрывать

## Точные значения
- путь: /srv/agent-ops/bin/releases_collect.py
- путь: /srv/agent-ops/data/releases_cards.json
- файл: releases-collect.timer
- команда: systemctl list-timers --all
- идентификатор: a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6
- число: 0.45 ratio
