# Числа

Значения измерены на развёртывании, из которого извлечены эти модули: один сервер с агентским
шлюзом, около 70 заданий по расписанию, хранилище состояния и API провайдеров. Это измерения, а не
эталонные тесты — ваши источники, цены и состав отказов будут другими. В каждой строке указано окно и
способ измерения, чтобы утверждение можно было перепроверить, а не принять на веру.

## Куда уходили токены (до)

Измерено на 393 прогонах заданий за 28 дней по журналу расхода рантайма.

| Строка | Токены | Доля | Примечания |
|---|---|---|---|
| Всего | 121,9 млн | 100% | 7,6% прогонов завершились ошибкой |
| Задание слежения (опрашивало источник, решало по каждому элементу) | 53,7 млн | 44% | 162 прогона, ~331 тыс. входных токенов за прогон |
| Три задания дайджестов | 26,3 млн | 22% | ~557 / 941 / 841 тыс. входных токенов за прогон |
| Транспорт/статус поезда | 13,9 млн | 11% | ~637 тыс. входных токенов за прогон |
| Обход оператора мимо скрипта | 5,4 млн | 4% | заменён детерминированным обходом |
| Избыточная проверка здоровья | 3,3 млн | 2,6% | дублировала набор эвалов |

Полезная колонка — размер входа за прогон: задание, читающее сотни тысяч входных токенов, либо
перечитывает мир, либо заново выводит то, что скрипт уже знает.

## После замен

```
mail    ok 28/28  $1.15  →  $0.041 за успех
infra   ok 96/99  $0.90  →  $0.009 за успех
```

## Как читать эти числа

- Это отношения, а не абсолюты. Развёртывания за ними различаются размером; переносится направление
  каждой колонки.
- У каждой цифры есть окно. Процент без окна — это настроение.
- Интереснее всего сравнения, пережившие проверку: смена модели, дешевле за токен и дороже за задачу;
  «новая» модель, поднявшая цену механической работы в 2,3–3,3 раза; и проблема лимитов, которая
  оказалась не про IP-адрес. Все три живут в модулях как правила, а не как байки.
